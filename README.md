## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v16+
- npm v8+

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/abaxley2/React-Portfolio-2023.git
cd React-Portfolio-2023

# 2. Install dependencies
npm install

# 3. Start the development server
npm start
```

The app will open at `http://localhost:3000/React-Portfolio-2023`.

### Deployment

```bash
npm run deploy
```

This runs the production build and pushes it to the `gh-pages` branch automatically.
